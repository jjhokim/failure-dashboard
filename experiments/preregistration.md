## 0. 이 실험이 주장하는 것과 주장하지 않는 것

**주장한다**
- 합성 정비기록에서 주입한 공통원인 구조를, 3채널(의미·구조·시간) 융합 + HDBSCAN이
  **얼마나 회수하는가**(내적 타당도, 주입값 회수 정확도).

**주장하지 않는다**
- 고장 원인의 **인과 판정** (FMECA·FTA·고장분석 절차의 몫)
- **실운용 성능** (합성데이터 기반이므로 일반화 주장 불가)
- Ao 조기경보(기능 2), CAI(기능 3) — 본 과제 범위 밖

## 1. 파일럿 고지 (중요)

합격기준 설계를 위해 **소규모 파일럿**(3~4시드)을 선행 실행했고, 그 관측치를
아래 「4. 합격기준」 설계에 참고했다. 이는 사전등록의 독립성을 일부 훼손할 수
있으므로 다음과 같이 통제한다.

1. 파일럿에서 관측된 값에 **맞춰 임계값을 낮추지 않았다.** (노이즈 기준 0.8 유지)
2. 임계값은 가능한 한 **절대 수치 대신 관계형 기준**(단조성·상대비교·CI 배제)으로 둔다.
3. 파일럿에 사용한 시드(0~3)는 본 실험 시드(0~7)에 포함되므로, **파일럿은 별도
   성능 근거로 인용하지 않는다.** 보고 수치는 본 실험 8시드 결과만 사용한다.

파일럿 관측 요약 (참고용, 성능 주장 아님):

| min_cluster_size | δ=0 노이즈비율 | δ=0 생성군집 수 | δ=1 ARI |
|---|---|---|---|
| 5  | 0.538 | 5.7 | 0.870 |
| 8  | 0.872 | 1.3 | 0.902 |
| 12 | 1.000 | 0.0 | 0.918 |

## 2. 데이터 생성 조건 (고정)

| 항목 | 값 | 비고 |
|---|---|---|
| `n_records` | 600 | 순위지표 표본 확보 |
| `n_clusters` | 10 | Precision@5 성립에 필요(≥5) |
| `cluster_size_dist` | **`geometric`** | `uniform`은 전 군집 크기를 균등화해 **규모 축의 변별력을 소거**함(파일럿 변동계수 0.03 vs 0.77) |
| `noise_ratio` | 0.2 | 단발성 고장 비율 |
| `expression_variance` | 0.5 | 기록자 표현 편차 |
| `n_systems` | 12 | Σ운용시간 분모 |
| `op_hours_per_day` | 8.0 | |
| `time_span_days` | 365 | |
| 시드 | **0 ~ 7 (8개)** | 모든 수치는 mean±std (R4) |

문장 생성기는 오프라인 `TemplateNarrator`를 사용한다(프롬프트 전문: `synth/prompts/`).

## 3. 탐지 조건

- 의미 채널: KoSBERT `snunlp/KR-SBERT-V40K-klueNLI-augSTS` 코사인 거리
- 구조 채널: LCN 트리 경로거리 / (최대깊이 × 2)
- 시간 채널: `1 - exp(-|Δt| / τ)`, **τ = 30일 고정**
- 융합: 채널별 min-max 정규화 후 가중합, 기본 가중치 (0.5, 0.25, 0.25)
- 군집화: `HDBSCAN(metric='precomputed')`

### 3-1. `min_cluster_size` 선택 규칙 (사전 고정)

> **m은 δ=0(무주입) 대조군에서 노이즈 비율 ≥ 0.8을 만족하는 `[5, 8, 12]` 중 최솟값으로
> 선택한다. 선택은 8시드 평균 기준이며, δ=0 조건만으로 결정한다.**

선택이 **귀무조건에서만** 이뤄지므로, 성능(δ>0의 ARI)에 맞춘 튜닝이 아니다.
즉 이 규칙은 "신호가 없을 때 구조를 지어내지 않을 것"을 보장하는
거짓양성 통제이며, 순환성을 만들지 않는다.

## 4. 합격기준 (실행 전 확정 — 이후 수정 금지)

### C1. 무주입 대조군 (δ = 0)
- **C1-a. 노이즈 비율 ≥ 0.8** (8시드 평균, 선택된 m 기준)
- **C1-b. ARI ∈ [-0.05, +0.05]** (유의 군집 미형성)

> 파일럿에서 m=5가 이 기준에 미달(0.538)하며 허위 군집 5.7개를 생성했다.
> **기준을 관측치에 맞춰 하향하지 않고 유지**하며, 대신 위 3-1 규칙으로 m을 선택한다.

### C2. 라벨 무작위 순열 음성 대조군
- **|ARI| < 0.05** (8시드 평균)

### C3. 주입 강도 단조성
- **δ ∈ {0, 0.25, 0.5, 0.75, 1.0}에 대해 평균 ARI가 단조 증가**
- 인접 δ 간 역전이 1쌍 이하이면 "대체로 단조"로 기술하고, 2쌍 이상이면 미충족으로 본다.

### C4. 채널 융합 우위
- **3채널 융합의 평균 ARI ≥ 단일 채널 최선값의 평균** (δ = 1.0 기준)

### C5. 우선순위화 (순위 지표)
- **Spearman ρ: 8시드 평균 > 0 이고, 부트스트랩 95% CI가 0을 포함하지 않을 것** (δ = 1.0)
- **Precision@5: 8시드 평균을 보고한다** (합격 임계값은 두지 않음 — 탐색적)
- **시드별 ρ에는 기준을 걸지 않는다.** 파일럿에서 n_clusters=4일 때 시드별 ρ가
  -0.4 ~ 1.0 (sd 0.51)로 요동했으며, 이는 군집 수가 적어 생긴 표본 문제였다
  (n_clusters=10에서 sd 0.18로 축소). 단일 시드 수치는 보고하지 않는다(R4).

### C5-1. 군집 대응(매칭) 규칙 — 사전 고정
산출 군집 ↔ 정답 군집 대응은 **각 산출 군집 내 최빈 정답 라벨**(다수결)로 정한다.
노이즈(-1)는 대응에서 제외한다. ρ가 매칭 규칙에 의존하므로 실행 전 고정한다.

### C6. 축 진단 (기준 아님 — 보고 의무)
- 규모/추세/치명도 3축의 **상관행렬을 함께 보고**한다.
- **잔차화(residualization)는 하지 않는다.** 사전 검토에서 "치명도가 규모와 중복"이라는
  가설이 있었으나, 파일럿 실측 결과 중복이 **확인되지 않았다**
  (`geometric` 조건에서 corr(size, crit) = +0.20). 근거 없는 보정을 적용하지 않는다.

## 6. 평가 지표

| 지표 | 정의 | 비고 |
|---|---|---|
| ARI | `sklearn.adjusted_rand_score` | **노이즈(-1)는 각각 독립 군집으로 처리하지 않고, 하나의 '노이즈 군집' 라벨로 유지한 채 계산**한다(처리 방식 고정) |
| Pairwise Precision / Recall | 동일 군집 쌍 기준 | 노이즈 쌍 제외 |
| Detection Delay | 주입 시점 t*_c 이후 슬라이딩 윈도우 재군집화에서 해당 군집 순도가 **0.8에 처음 도달할 때까지의 누적 고장 건수** | 미도달 시 `NA`로 기록하고 도달률을 함께 보고 |
| Spearman ρ | 주입 Cm 기반 정답 순위 vs 산출 순위 | 매칭 규칙 C5-1 |
| Precision@k | k = 5 | |

우선순위화 치명도는 **관측치 대체값만** 사용한다
(`λ_obs = 건수 / Σ운용시간`, `β·α ≈ effect_class(EFF) 비율`).
주입 β·α·λ는 정답 순위 산출에만 쓰이며 탐지·점수 산출에 전달되지 않는다.
